# Roxiler

This repository contains the **Store Rating Platform** project with:

- **Backend**: NestJS API (`store-rating-platform/backend`)
- **Frontend**: React + Vite app (`store-rating-platform/frontend`)

## Project Structure

```text
Roxiler/
└── store-rating-platform/
    ├── backend/
    └── frontend/
```

## Getting Started

### 1) Backend setup

```bash
cd store-rating-platform/backend
npm install
npm run start:dev
```

Useful backend scripts:
- `npm run build`
- `npm run lint`
- `npm run test`

### 2) Frontend setup

```bash
cd store-rating-platform/frontend
npm install
npm run dev
```

Useful frontend scripts:
- `npm run build`
- `npm run lint`
- `npm run preview`

## Notes

- Backend and frontend have their own `README.md` files for framework-specific details.
